# transitioning-genai-to-production
This repository provides the data and code used in the study reported in **<Transitioning From GenAI Tooling to Production: Exploring the Diversity of AI Projects on GitHub>**.  

It contains:
- The original metadata dataset
- Scripts to filter prompts and collect repository-level information
- The final repository dataset used in the analysis
- Processed result files in `study_results/`
- Analysis scripts used to generate the results in the paper
